# 仓库与本地数据隔离

仓库仅发布程序、通用配置、合成测试与文档。车辆品牌、型号候选配置是软件支持范围，不表示任何操作者的车辆所有权或身份。

## 不提交的内容

- 全部 data 内容（仅 .gitkeep 例外）：真实帧、诊断响应、动作标记、SQLite、审计、报告、私有会话清单与旧文档。
- 截图、测试产物、CSV / ASC / BLF / candump 等采集导出、备份、运行时缓存。
- VIN、车牌、具体设备蓝牙地址/序列号、GPS、住址、本机用户名和个人绝对路径。
- .env、认证材料、密钥、证书以及个人工具配置。

示例响应必须是明确构造的合成 fixture；不复制完整实车通信日志到源码或测试。公开状态文档仅记功能与验证边界，不包含个人测试时间线或采集值。

## 提交前

审查 `git diff --cached` 和 `git diff --cached --name-only`，运行 `python scripts/check_repository_privacy.py`。检查器对暂存内容检查禁止目录/扩展名、密钥、个人 Windows 路径、MAC 地址和 VIN 候选；只报告路径与类别，不转储命中内容。它不是完整的敏感信息检测器，仍需人工检查未知格式的个人信息。

初次提交使用 GitHub noreply 邮箱，避免泄漏个人邮箱。不要依赖 Private 仓库替代数据清理；以后改为 Public 前也必须重新审查完整历史。
