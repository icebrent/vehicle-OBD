# 验证范围

自动化检查由 `scripts/test.ps1` 执行。当前基线为 122 项 pytest、6 项 Vitest、7 项 Playwright；后续新增检查可能改变数量。Ruff、Prettier、TypeScript 与 Vite 构建均纳入检查。

- 后端：标准/扩展 ID、DLC、非法行、分块串口读取、BUFFER FULL、端口错误、命令白名单、重复连接/停止、队列/磁盘异常、原始记录及回放。
- DID：固定合成单帧响应、符号电流、10 组身份、DID 与 schema 对应、单响应后缀、核心/分组交错、停止时无后续发送、首次有效数据才保存、离线回放不打开设备。
- 前端：不回填 Mock、旧值失效、不同时间的派生功率保护、分组完整性与过期、选择分组、动作标记、回放、主题、暂停与原始工作台。
- 离线分析：字段与分组隔离、备注分段、空输入和缺失数据不伪造。

Playwright 使用隔离数据目录和端口，硬件入口关闭。截图与运行产物被 Git 忽略，公开仓库没有个人硬件截图。Mock soak 可检查约一分钟实时传输及浏览器断开后的后台采集，不等于长时间耐久或真实总线性能认证。

硬件曾完成短时原始接收与固定诊断读取的功能验证；错误 121、BUFFER FULL、混合 ID 覆盖、RTR 实际输出、无 ACK 电气状态及长时吞吐仍有未验证项。协议响应成功不等于全部物理量含义已验证，分组和换算保留 Experimental 标记。私人会话清单、读数和具体时间留在本机，不作为公共测试 fixture。

构建可能提示 ECharts chunk 较大；当前不影响构建成功。Starlette/httpx 测试适配存在上游弃用提示，尚非测试失败。
