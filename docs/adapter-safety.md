# 适配器命令与边界

依据 [OBDLink 开发者页面](https://www.obdlink.com/developers/)和 [Family Reference and Programming Manual](https://www.obdlink.com/frpm)，特别是 7.2 / 8.4 / 8.6 / 8.8 / 8.9 / 8.10 / 11.2。代码白名单约束本程序，不替代独立分析仪的电气验证。

## 被动监听

连接仅 ATI / STDI。配置 ATE0、ATL0、ATS0、ATH1、ATCAF0、ATD1，STP 31、人工选择 STPBR、STPBRR 验证，STCMM 0 无 ACK 接收，关闭自动流控和接收分段。STFAC 后显式增加 STFPA 零掩码；混合 11/29-bit 覆盖仍需台架验证，不能仅凭清过滤器认定全部可见。

使用 STM 16，不使用 STMA 或无限 STM；每批正常结束后等待再开始，有采样间隙。停止以单个空格退出监控并消费提示符；异常关闭后不自动重启。适配器遗留周期发送、其他软件配置和 NVM 状态不属于本程序已验证范围。仅支持 HS-CAN pins 6/14。

## 主动只读诊断

与被动命令分开管理，绝不称为完全静默。Mode 01 的独立一次性模块只查固定支持列表及已声明支持的 010C / 010D / 0142，不盲试其余 PID。

实验性 DID 模块固定 STP 33、地址 7E7 → 7EF、核心四项与可选 40 项分组请求。STPTRQ 500，每次响应后等待 0.5 秒；固定单条预期响应后缀 1 减少额外等待。核心与分组按顺序交错。白名单拒绝任意服务、任意 DID 和串口文本注入。STCMM 0 只控制监控 ACK，不能使主动诊断成为被动通信。

无 ECU 扫描、自动协议探测、VIN/DTC 读取、清码、服务 10 会话切换、服务 27 安全访问、服务 2E 写入或通用 CAN 发送 API。自动 ISO-TP 流控和分段关闭，仅接收完整单帧；负响应、超时、格式异常停止，不自动扩大请求范围或重试。

原始与诊断独占适配器。连接成功后主动停止、断开或重启后端必须取得操作者同意。默认仅 localhost，硬件入口默认关闭，记录默认关闭。设备和车辆身份不写入公开文档。
